# Realest Entertainment App — REP Login Screen

This project contains the initial login UI for REP (Realest Entertainment Produce) for iOS using UIKit + MVC + Storyboard.

## Files Included

- `Main.storyboard` — UI for REPLoginVC
- `REPLoginViewController.swift` — Logic + outlets
- `Assets.xcassets` — Placeholder logo
- `AppDelegate.swift`, `SceneDelegate.swift`
- `Info.plist` — Main storyboard setup

## To Run

1. Open in Xcode 14+ on macOS
2. Set target to iPhone 14+
3. Run on simulator
